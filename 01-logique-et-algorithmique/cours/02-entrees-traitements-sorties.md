# 02 — Entrées, traitements, sorties

Un programme transforme généralement des données d'entrée en résultat.

Exemple :
prix = 5000
quantite = 3
total = prix × quantite
sortie = 15000

## Exercice

Identifier entrée, traitement et sortie pour :
1. une moyenne ;
2. Celsius → Fahrenheit ;
3. un panier d'achat ;
4. une vérification de majorité.
