# 01 — Algorithmes

Un algorithme est une suite ordonnée d'étapes permettant d'obtenir un résultat.

## Exemple

Problème : préparer une boisson chaude.
1. prendre une tasse ;
2. chauffer l'eau ;
3. ajouter la boisson ;
4. verser l'eau ;
5. mélanger.

## Exercice

Écrire en langage naturel l'algorithme pour se connecter à un compte sur un site web.
