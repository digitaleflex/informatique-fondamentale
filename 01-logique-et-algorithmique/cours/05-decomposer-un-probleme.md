# Décomposer un problème

## Objectif
Transformer un énoncé complexe en petites opérations compréhensibles.

## Méthode
1. Définir le résultat attendu.
2. Identifier les entrées.
3. Lister les règles.
4. Découper en étapes.
5. Identifier les cas limites.
6. Tester avec de petits exemples.

## Exemple
Pour une caisse : données client → prix → quantité → sous-total → réduction → total → validation.

## Erreur fréquente
Commencer à coder avant d'avoir compris le problème.

## À retenir
Un bon programme commence souvent par une bonne décomposition.
