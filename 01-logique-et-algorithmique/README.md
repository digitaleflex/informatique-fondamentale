# Niveau 01 — Logique & algorithmique

## Objectif

Apprendre à résoudre un problème avant de penser au langage de programmation.

## Compétences
- entrée / traitement / sortie ;
- écrire un algorithme ;
- utiliser variables ;
- conditions ;
- boucles ;
- fonctions ;
- listes ;
- décomposition de problèmes.

## Règle

Le raisonnement vient avant le code.
