# Schémas pédagogiques

Les schémas servent à visualiser les relations et processus difficiles à comprendre uniquement avec du texte.

Convention recommandée :
- bleu : concept ;
- vert : acquis / résultat ;
- jaune : attention ;
- rouge : erreur ;
- violet : challenge.

La couleur doit porter une information, pas seulement décorer.
