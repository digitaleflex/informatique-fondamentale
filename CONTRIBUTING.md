# Contribuer au curriculum

Toute contribution doit améliorer l'apprentissage.

## À privilégier
- explications simples ;
- exercices progressifs ;
- problèmes authentiques ;
- consignes autonomes ;
- solutions séparées ;
- documentation claire.

## À éviter
- suringénierie ;
- difficulté artificielle ;
- copie de tutoriels ;
- frameworks introduits trop tôt.

## Convention de chapitre

Un niveau peut suivre :
course/
exercises/
challenges/
solutions/
projects/

## Convention de commit

- docs: add ...
- feat: add ...
- fix: correct ...
- refactor: reorganize ...

## Contrôle pédagogique

Avant d'ajouter un exercice :
- le prérequis est-il enseigné ?
- l'énoncé est-il compréhensible seul ?
- la difficulté progresse-t-elle ?
- la compétence est-elle réellement mesurée ?
