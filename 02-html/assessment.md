# Assessment — HTML

| Domaine | Critère d'acquisition |
|---|---|
| Structure | construire l'arbre avant de coder |
| Sémantique | justifier les balises |
| Liens/médias | gérer chemins et alternatives |
| Formulaires | relier labels, champs et contraintes |
| Accessibilité | réussir un parcours clavier |
| Debugging | isoler la cause |
| Autonomie | produire une page sans tutoriel |

## Épreuve finale
Construis une page de portfolio en 60–90 minutes à partir d'un brief court.

Interdits : copier un template, framework, CSS avant validation de la structure, corrections au hasard.

Explique oralement l'arbre du document, cinq choix sémantiques et trois décisions d'accessibilité.
