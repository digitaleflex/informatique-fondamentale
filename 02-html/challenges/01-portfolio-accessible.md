# Challenge — Portfolio accessible

**Difficulté :** 🔴 Challenge

Construis la structure HTML d'un portfolio professionnel : identité, navigation, présentation, projets, compétences, parcours, contact et pied de page.

Contraintes : sémantique, clavier, formulaires correctement étiquetés, alternatives d'images, aucun CSS ni framework.

Fournis un schéma de l'arbre HTML et au moins dix cas de test.
