# Correction — Structure d'une page

La correction vérifie le raisonnement, pas une copie caractère par caractère.

```text
body
├── header
│   └── nav
├── main
│   ├── section — présentation
│   └── section — compétences
└── footer
```

Points de contrôle : un seul `main` pour le contenu principal, titres hiérarchisés, navigation dans `nav`, pas de `div` utilisée uniquement pour son apparence.
