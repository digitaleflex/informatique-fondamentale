# Debugging — Lien cassé

**Symptôme :** « Contact » mène à une 404.

Procédure : copier l'URL produite, comparer avec le chemin attendu, vérifier le contexte du fichier, vérifier les majuscules/minuscules, puis tester la destination.

**Piège :** un chemin relatif est résolu à partir de l'emplacement du document courant.
