# Exercice 01 — Structure d'une page

**Difficulté :** 🟢 Découverte

Construis une page « À propos » contenant un en-tête, une navigation, un contenu principal, une section biographique, une section compétences et un pied de page.

### Contraintes
- structure sémantique ;
- hiérarchie de titres cohérente ;
- aucun CSS ;
- expliquer chaque choix.

### Tests
1. JavaScript désactivé ;
2. navigation au clavier ;
3. lecture du document sans regarder le rendu visuel.
