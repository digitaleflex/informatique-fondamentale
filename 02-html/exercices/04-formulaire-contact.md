# Exercice 04 — Formulaire de contact

**Difficulté :** 🟡 Application

Construis un formulaire contenant nom, e-mail, sujet et message.

Contraintes : chaque champ possède un `label`, les types sont adaptés, les champs nécessaires sont obligatoires, les valeurs d'autocomplétion sont pertinentes et un bouton d'envoi est présent.

Explique pourquoi la validation HTML ne suffit pas pour sécuriser une future API.
