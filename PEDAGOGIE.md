# Cadre pédagogique

Chaque notion suit la boucle :

**Cours → Schéma → Exemple → Exercice guidé → Exercice autonome → Correction → Debugging → Challenge → Projet → Évaluation → Réflexion**

## Principes

1. Comprendre avant mémoriser.
2. Faire avant regarder la correction.
3. Expliquer son raisonnement.
4. Pratiquer sur des problèmes nouveaux.
5. Transformer les erreurs en apprentissage.

## Niveaux d'exercices

- 🟢 Découverte
- 🟡 Application
- 🟠 Autonomie
- 🔴 Challenge

## Règle des corrections

Une correction doit expliquer le raisonnement, les étapes, les erreurs fréquentes et une variante.

## Règle des visuels

Un schéma ou une illustration n'est ajouté que s'il facilite réellement la compréhension.
