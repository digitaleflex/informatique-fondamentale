# Informatique Fondamentale → Web Full-Stack

Parcours progressif destiné à une débutante qui souhaite construire des bases solides en informatique et évoluer vers le développement web Full-Stack moderne.

## Philosophie

Ce repository est un curriculum vivant : les contenus seront enrichis et améliorés au fur et à mesure de la progression de l'apprenante.

Principes :
- compréhension avant mémorisation ;
- pratique avant théorie excessive ;
- résolution de problèmes ;
- progression par niveaux ;
- projets concrets ;
- Git et GitHub ;
- qualité du code, documentation et autonomie.

## Règle de progression

Un niveau est considéré comme acquis lorsque l'apprenante peut :
1. expliquer les notions ;
2. réaliser les exercices sans recopier ;
3. résoudre un challenge autonome ;
4. produire un mini-projet ;
5. expliquer ses choix ;
6. corriger ses propres erreurs.
