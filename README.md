# Informatique fondamentale → Full-Stack moderne

Parcours progressif pour partir de zéro et construire une compréhension solide de l'informatique avant d'aborder les frameworks modernes.

## Philosophie

> Comprendre les principes avant les outils.

Le parcours combine théorie, schémas, exercices, corrections, debugging, challenges, projets et évaluations.

## Boucle pédagogique

**Cours → Schéma → Exemple → Exercice → Correction → Debugging → Challenge → Projet → Assessment → Réflexion**

## Règles

- tenter avant de regarder une correction ;
- expliquer son raisonnement ;
- tester les cas limites ;
- utiliser la documentation comme outil de travail ;
- ne jamais confondre « ça fonctionne » avec « je comprends ».

## Projet final

La progression converge vers une application Full-Stack moderne de type **TaskFlow** : authentification, projets, tâches, API, PostgreSQL, Prisma, tests et déploiement.
