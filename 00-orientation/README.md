# Niveau 00 — Orientation informatique

## Objectif

Comprendre l'environnement informatique avant de programmer.

## Compétences
- expliquer le rôle d'un ordinateur ;
- distinguer matériel et logiciel ;
- comprendre le rôle d'un OS ;
- manipuler fichiers et dossiers ;
- utiliser le terminal de base ;
- comprendre quelques formats de fichiers ;
- découvrir les notions de navigateur, client et serveur.

## Chapitres
1. Ordinateur et composants
2. Système d'exploitation
3. Fichiers et dossiers
4. Extensions
5. Terminal
6. Premières notions du Web

## Validation

Projet : construire et expliquer un espace de développement depuis le terminal.
