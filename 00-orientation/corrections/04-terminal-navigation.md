# Correction — Naviguer dans le terminal

Le problème teste quatre compétences : connaître son emplacement, observer le contenu, créer des éléments et se déplacer sans perdre le contexte.

Logique : où suis-je ? → qu'y a-t-il ici ? → créer → entrer → travailler → revenir.

Les commandes exactes peuvent varier selon Windows, Linux ou macOS. L'objectif est de comprendre la navigation.

## Erreur fréquente
Lancer une suppression sans vérifier le chemin courant.
