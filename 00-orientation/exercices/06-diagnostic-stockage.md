# Exercice 06 — Diagnostic du stockage

**Difficulté :** 🟠 Autonomie

Ton ordinateur signale que le stockage est presque plein.

Décris une procédure pour : mesurer l'espace disponible ; identifier ce qui occupe l'espace ; distinguer l'utile de l'inutile ; décider quoi supprimer ; vérifier le résultat.

**Interdit :** supprimer au hasard.
