# 03 — Fichiers et dossiers

Un système de fichiers organise les données en fichiers et dossiers.

Crée :
formation/
├── cours/
├── exercices/
├── projets/
└── ressources/

Puis :
1. créer un fichier dans chaque dossier ;
2. renommer deux fichiers ;
3. déplacer un fichier ;
4. copier un fichier ;
5. supprimer un fichier.
